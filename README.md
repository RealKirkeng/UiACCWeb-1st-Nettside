# UiA Case Club — Website

**The official welcome and informational website for UiA Case Club at the University of Agder, School of Business and Law in Kristiansand.**

> A modern, friendly, and fully static HTML/CSS/JS website — built with zero external build tools or SaaS dependencies. Features a dual-focus experience for student recruitment & corporate partnerships, sticky animated scrolling sections, and modern rounded geometry.

---

## Project Structure

```
UiACCweb/
├── index.html        # Welcome hub (dual audience, sticky journey, partnerships, FAQ)
├── about.html        # Club history, mission, vision, and leadership
├── approach.html     # 4 core training pillars and semester curriculum roadmap
├── competitions.html # Competition track record and case solving workflow
├── contact.html      # Reachout hub & detailed contact form
├── style.css         # Token-based design system, rounded components & animations
├── script.js         # Parallax, scroll reveal, sticky journey tracker, audience switcher
├── logo.png          # UiA Case Club brand logo
├── favicon.png       # Brand favicon
├── KRS-Luftbilde.png # High-res campus aerial background
├── hero_bg.jpg       # Hero banner photograph
└── about_img.jpg     # About section team photograph
```

## Key Features

1. **Dual-Audience Interactive Gateway**:
   - **For Students**: Direct access to application forms, weekly workshop benefits, competition delegations, and career acceleration.
   - **For Businesses & Companies**: Partnership avenues, hosting on-campus Case Nights, direct talent recruitment, and competition sponsorship.
2. **Sticky Animated Scrolling Experience**:
   - Interactive 4-step progress sidebar tracking the student journey from onboarding to Nordic podiums.
3. **Responsive & Friendly Modern Design**:
   - Soft rounded edges (`border-radius: 12px–24px` / pill buttons), smooth scroll transitions, and subtle glassmorphic navigation.
4. **Floating Quick-Contact Widget**:
   - Expandable contact widget with direct links to the student application form and quick email trigger.
